# Data-Handling Plan

| Stage | Planned control |
|---|---|
| Collection | Collect only responses needed for the approved research question. |
| Minimisation | Avoid names, addresses, account identifiers, passwords, banking details, and authentication codes unless justified and approved. |
| De-identification | Remove direct identifiers where possible and assess re-identification risk. |
| Storage | Use an organisation-approved, access-controlled location; do not store raw data in public folders. |
| Access | Limit access to authorised researchers and supervisors who need it. |
| Use | Use data only for the purpose described to participants and approved by the supervisor. |
| Reporting | Prefer aggregate findings; do not publish identifiable individual responses. |
| Retention | Agree a specific retention period with the supervisor before collection. |
| Deletion | Securely delete data and unnecessary copies when the approved period ends. |
| Incident response | Promptly report loss or exposure through the organisation's approved process. |

**Example:** For a mock phishing exercise, record whether a warning sign was identified or a safe response was selected. Do not collect real passwords or attempt account access.

Confirm storage, access, retention, deletion, and withdrawal arrangements before collecting data.
