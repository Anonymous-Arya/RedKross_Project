## Project overview
This project develops an ethics and safety framework for a proposed simulated cybersecurity user study. It covers informed consent, voluntary participation, withdrawal, privacy, data minimisation, controlled simulation, access restrictions, retention and deletion, risk mitigation, and debriefing.

## Objectives
- Explain informed consent and voluntary participation.
- Minimise personal and sensitive information.
- Describe safe data storage, access, retention, and deletion.
- Identify risks and propose mitigation measures.
- Provide a respectful debriefing plan.

## Evaluation and limitations
The current evaluation is a document coverage review, not a live experiment. Risk ratings are illustrative. Before any actual study, the supervisor must confirm the scenario, consent wording, eligibility, contact details, storage, retention, withdrawal process, and required approvals.

## Safety and privacy
- Do not collect real passwords, payment details, or authentication codes.
- Do not send real phishing messages or run unauthorised security tests.
- Do not upload confidential information or participant personal data.
- Obtain required approval before recruitment or data collection.
